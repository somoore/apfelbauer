# Security Policy

## About This Repository

This repository contains security research demonstrating architectural issues in Apple's FoundationModels framework and Apple Intelligence enablement on macOS Tahoe. All findings were disclosed to Apple Product Security prior to public release.

## Reporting Additional Issues

If you discover additional vulnerabilities related to these findings:

1. **Do not open a public issue.** Security issues should be reported privately.
2. **Report to Apple:** Use [Apple's security reporting page](https://support.apple.com/en-us/102549) for vulnerabilities in Apple products.
3. **Contact the researcher:** Reach out to Scott Moore via GitHub for coordination on related research.

## Responsible Use

The proof-of-concept code in this repository is provided for defensive security research and authorized testing only. Do not use these tools against systems you do not own or have explicit authorization to test.
